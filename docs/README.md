## Quick Reference — System At a Glance

```
Cron (:00/:15/:30/:45)
    └▶ _scheduledImpl() [worker.js]
        ├▶ Top 40 priority sources → FEED_QUEUE
        ├▶ [/4 cycles] recalculatePriorities + probeDomainsForCareers
        ├▶ [/8 cycles] runSearchExpansion (Bing→Brave→static)
        └▶ [midnight] sendDailyReport

FEED_QUEUE → processFeeds() [6 connectors]
    └▶ Circuit breaker → fetch → parse → normalize → in-mem dedup
        └▶ batchInsertJobs(D1) → JOB_QUEUE

JOB_QUEUE → evaluateJobs() [scoring/relevance-v4.js]
    └▶ Keyword gate → [AI embedding] → 13-layer scoreJob()
        └▶ score ≥ threshold → ALERT_QUEUE

ALERT_QUEUE → sendAlerts() [notifications.js]
    └▶ Discord rich embed + Telegram MarkdownV2 (5× retry, 75min resilience)
```
